DARS 21 · MODUL C — MA'LUMOTLAR

SQL 1: bazadan kerakli qatorni so'rab olish

Modul C boshlandi. Va u Eloquent bilan emas, SQL bilan boshlanadi — bu ataylab, xuddi Modul A dagi mini-framework kabi. SQL'ni bir marta o'z qo'lingiz bilan yozgandan keyin Eloquent sehr emas, qulaylik bo'lib ko'rinadi.

📱 O'qish ≈ 11 daqiqa 💻 Amaliyot ≈ 18 daqiqa Kerak: Dars 20

Bu darsda nimalar bor
  1. SQL'ni qanday ishga tushiramiz php artisan db ishlamaydi — Laravel'ni qo'lda yuklovchi skript yozamiz.
  2. «A facade root has not been set» Uchinchi qatorni unutganda chiqadigan xato va uning ma'nosi (15-dars).
  3. DB::statement va DB::select Natija qaytarmaydigan va qaytaradigan so'rovlar.
  4. Jadval yasash CREATE TABLE · PRIMARY KEY · NOT NULL · DEFAULT.
  5. SELECT ning barcha shakllari WHERE · AND/OR · ORDER BY · LIMIT · COUNT · AS.
  6. 🔑 NULL — «noma'lum» = NULL ishlamaydi; != shartlari NULL qatorlarni jimgina tashlaydi.
  7. 🔒 SQL injection Foydalanuvchi qiymati faqat ? parametr bilan.
Nega SQL Eloquent'dan oldin

Uch sabab:

  1. Intervyuda so'raladi. «Faqat Eloquent bilaman» deyish — junior uchun jiddiy kamchilik. JOIN, indeks, GROUP BY savollari deyarli har suhbatda bo'ladi.
  2. Eloquent SQL yozadi. U sehr emas — u sizning nomingizdan SQL tuzadi. Sekin sahifani tuzatish uchun u qanday SQL yozganini o'qish kerak bo'ladi (Modul H — N+1 muammosi). SQL bilmasangiz — o'qib bo'lmaydi.
  3. Ba'zan Eloquent yetmaydi. Murakkab hisobotlarda toza SQL yoziladi.

Yaxshi xabar: SQL o'qishga oson til. U inglizcha gapga o'xshaydi: «select nom from vakansiyalar where maosh > 700».

SQL'ni qanday ishga tushiramiz

Bitta amaliy muammo bor: sizning kompyuteringizda SQLite buyruq qatori o'rnatilmagan. Ya'ni php artisan db ishlamaydi (tekshirib ko'rasiz — xato beradi).

Yechim esa foydali chiqadi: SQL'ni kichik PHP faylida yozib, oddiy php bilan ishga tushiramiz. Faylning boshida uch qator bo'ladi:

sql/*.php — har faylning boshi
<?php use Illuminate\Support\Facades\DB; require __DIR__ . '/../vendor/autoload.php'; $app = require_once __DIR__ . '/../bootstrap/app.php'; $app->make(Illuminate\Contracts\Console\Kernel::class)->bootstrap();

Bu uch qator sizga tanish bo'lishi kerak — 17-darsda Laravel'ning public/index.php faylini o'qiganda ko'rgansiz:

QatorNima qiladi
require vendor/autoload.phpAutoload (12-dars) — klasslarni topish
require bootstrap/app.phpContainerni yasaydi (15 va 17-darslar)
->bootstrap()Sozlamalarni yuklaydi — bazaga ulanish shu yerdan keladi
Uchinchi qatorni unutsangiz — foydali xato

Amaliyotda ataylab sinab ko'rasiz:

PHP Fatal error: Uncaught RuntimeException: A facade root has not been set. in …/Facade.php:361

«Fasadning ildizi o'rnatilmagan» — ya'ni DB:: ishlatmoqchi bo'ldik, lekin container tayyor emas (15-dars!). Bu xato Laravel'da tez-tez uchraydi va endi siz uning ma'nosini bilasiz. DB nima ekanini — fasad — Modul G da ochamiz.

Jadval va ma'lumot

SQL o'rganish uchun ma'lumot kerak. Uni ham SQL bilan yasaymiz:

sql/01-jadval.php
DB::statement(' CREATE TABLE vakansiyalar ( id INTEGER PRIMARY KEY AUTOINCREMENT, nom TEXT NOT NULL, maosh INTEGER, shahar TEXT, faol INTEGER DEFAULT 1 ) ');
  • Jadval = 5-darsdagi «yozuvlar ro'yxati». Har qator = bitta yozuv, har ustun = maydon.
  • id INTEGER PRIMARY KEY AUTOINCREMENT — birlamchi kalit: har qatorning takrorlanmas raqami, o'zi ortib boradi.
  • NOT NULL — bu ustun bo'sh bo'lolmaydi (20-darsdagi required ga o'xshaydi, lekin baza darajasida).
  • DEFAULT 1 — qiymat berilmasa 1 qo'yiladi (6-darsdagi standart parametr g'oyasi).
  • SQLite'da faol uchun BOOLEAN yo'q — 0/1 ishlatiladi.

DB::statement() — natija qaytarmaydigan SQL uchun (CREATE, INSERT, UPDATE). DB::select() — natija qaytaradigan SQL uchun.

SELECT — o'qishning barcha shakllari

SELECT nom, maosh FROM vakansiyalar WHERE shahar = 'Toshkent' AND faol = 1 ORDER BY maosh DESC LIMIT 2

O'qib ko'ring: «nom va maoshni ol, vakansiyalar jadvalidan, shartga mos bo'lganlarni, maosh bo'yicha kamayish tartibida, faqat 2 ta». Tartib har doim shunday: SELECT → FROM → WHERE → ORDER BY → LIMIT.

🔒 SQL'ni qo'lda yopishtirib yozmang

Foydalanuvchi kiritgan qiymatni SQL satriga qo'shib yozish — SQL injection deb ataladigan xavfsizlik teshigi:

// ❌ HECH QACHON SHUNDAY QILMANG DB::select("SELECT * FROM vakansiyalar WHERE nom = '{$request->input('nom')}'");

To'g'ri yo'l — parametr ishlatish:

// ✅ To'g'ri DB::select('SELECT * FROM vakansiyalar WHERE nom = ?', [$nom]);

? o'rniga qiymat xavfsiz qo'yiladi — u SQL sifatida emas, ma'lumot sifatida ishlanadi. Bu 13-darsdagi XSS qoidasining ukasi: XSS — chiqishda, SQL injection — bazaga so'rov yuborishda. Ikkalasi ham bitta sababdan: tashqi ma'lumotni kod deb ishlatish. Buni Modul I da (xavfsizlik darsi) batafsil ko'ramiz; Eloquent esa buni o'zi qiladi.

💻 Amaliy qism kompyuterda

Amaliyotda sql/ papkasida ikkita fayl yozasiz: birinchisi jadval yasab 5 qator qo'shadi, ikkinchisi beshta xil SELECT ni bajarib natijalarni chiqaradi. Yo'lda php artisan db nega ishlamasligini va «facade root has not been set» xatosini ham ko'rasiz.

Amaliyot

  1. IshTop'ga o'ting va php artisan db ni sinab ko'ring

    Nega alohida usul kerakligini o'z ko'zingiz bilan ko'rasiz.

  2. Jadval yasovchi faylni yozing

  3. Uchinchi qatorni olib tashlab, xatoni ko'ring

    15-darsdagi container bilimini ishga solamiz.

    grep -v 'Kernel::class' sql/01-jadval.php > sql/xato.php php sql/xato.php 2>&1 | head -1 rm sql/xato.php PHP Fatal error: Uncaught RuntimeException: A facade root has not been set. in …/Facade.php:361

Sinab ko'ramiz

Natijani taxmin qiling

Jadvalga oltinchi qator qo'shildi — uning shahar ustuni NULL (ya'ni «qiymat yo'q», 2-darsni eslang):

qo'shilgan qator
INSERT INTO vakansiyalar (nom, maosh, shahar, faol) VALUES ('Sirli ish', NULL, NULL, 1)

Endi jami 6 qator bor. Uchta so'rov nechta qator qaytaradi?

so'rovlar
A) SELECT * FROM vakansiyalar WHERE shahar = NULL B) SELECT * FROM vakansiyalar WHERE shahar IS NULL C) SELECT * FROM vakansiyalar WHERE shahar != 'Toshkent'
Javobni ko'rish
A) 0 qator ← hech narsa! B) 1 qator ← Sirli ish C) 1 qator ← faqat Laravel dasturchi (Samarqand)

A — 0 qator. shahar = NULL hech qachon rost bo'lmaydi. SQL'da NULL — qiymat emas, «noma'lum». Noma'lum narsani biror narsaga tenglashtirish natijasi ham noma'lum, ya'ni «rost emas». Shuning uchun NULL ni tekshirish uchun maxsus so'z bor: IS NULL / IS NOT NULL.

C — eng kutilmagani. 1 qator, 2 emas. «Toshkent emas» degan shartga mantiqan Sirli ish ham (shahri yo'q) tushishi kerak edi. Lekin NULL != 'Toshkent' ham noma'lum beradi — demak qator chiqarib tashlanadi.

Amaliy xulosa: NULL bo'lishi mumkin bo'lgan ustunni shartda ishlatganda ehtiyot bo'ling. «Toshkentda bo'lmaganlarning hammasi» kerak bo'lsa, aniq yozish kerak: WHERE shahar != 'Toshkent' OR shahar IS NULL.
Bu ish joyidagi klassik bug': hisobotdan qatorlar «g'oyib bo'ladi», sababi esa NULL.

SAVOL 1 Nega SQL Eloquent'dan oldin o'rganiladi?

Eloquent sizning nomingizdan SQL tuzadi. Sekin sahifani tuzatish uchun u yozgan SQL'ni o'qish kerak bo'ladi (Modul H). Va intervyuda SQL so'raladi.

SAVOL 2 WHERE shahar = NULL nima qaytaradi?

NULL — «noma'lum», shuning uchun uni = bilan solishtirish hech qachon rost bo'lmaydi. To'g'ri yo'l — IS NULL.

SAVOL 3 Foydalanuvchi kiritgan qiymatni SQL'ga qanday qo'shiladi?

DB::select('... WHERE nom = ?', [$nom]) — qiymat ma'lumot sifatida ishlanadi, SQL sifatida emas. Satrga qo'shib yozish SQL injection teshigini ochadi.

Eslab ayting

Avval o'zingiz javob bering, keyin ochib tekshiring. Oxirgi ikkitasi — 20-darsni takrorlash.

SELECT so'rovining tartibi qanday?

SELECT (qaysi ustunlar) → FROM (qaysi jadval) → WHERE (shart) → ORDER BY (saralash) → LIMIT (nechta). Tartib o'zgarmaydi.

DB::statement va DB::select farqi?

statement — natija qaytarmaydigan SQL (CREATE, INSERT, UPDATE). select — natija qaytaradigan SQL.

NULL bilan ishlashning qoidasi nima?

= yoki != ishlamaydi — IS NULL / IS NOT NULL kerak. Va NULL bo'lishi mumkin bo'lgan ustun shartda qatorni jimgina chiqarib tashlashi mumkin.

↩︎ Takrorlash: validate() nima qaytaradi?

Faqat qoidada sanab o'tilgan maydonlarni. Shuning uchun bazaga yozishda $request->all() emas, qaytgan qiymat ishlatiladi.

↩︎ Takrorlash: old() nima uchun kerak?

Validatsiya xatosidan keyin foydalanuvchi kiritgan qiymatlar formada saqlanib qolishi uchun — aks holda hammasini qaytadan to'ldiradi.

Cho'ntak xulosasi
  • SQL skripti uchta qator bilan boshlanadi: autoload → bootstrap/app.php → bootstrap(). Uchinchisi yo'q bo'lsa: «A facade root has not been set».
  • DB::statement() — natija qaytarmaydigan SQL · DB::select() — qaytaradigan.
  • Tartib: SELECT → FROM → WHERE → ORDER BY → LIMIT.
  • Matn SQL'da bittalik tirnoqda: 'Toshkent'.
  • ORDER BY ... DESC kamayish · ASC o'sish (standart) · COUNT(*) AS soni.
  • 🔑 NULL — qiymat emas, «noma'lum». = NULL ishlamaydi → IS NULL. Va != shartlari NULL qatorlarni jimgina tashlab ketadi.
  • 🔒 Foydalanuvchi qiymati SQL'ga faqat parametr bilan: '... = ?', [$nom]. Aks holda — SQL injection.
  • Jadval = yozuvlar ro'yxati (5-dars) · PRIMARY KEY = takrorlanmas raqam · NOT NULL, DEFAULT — baza darajasidagi qoidalar.
🌱 Keyingi dars

Bugun faqat o'qidik. 22-darsda yozamiz va bog'laymiz: INSERT ni chuqurroq, UPDATE, DELETE, va eng muhimi — JOIN: ikki jadvalni bir-biriga ulash.

JOIN muhim, chunki real ma'lumot bir jadvalda sig'maydi: vakansiya kompaniyaga tegishli, ariza nomzodga. Bu 5-darsdagi «ichma-ich massiv» ning bazadagi shakli — va C modulining qolgan qismi (Eloquent bog'lanishlari) butunlay shu tushunchaga tayanadi. Intervyuda ham JOIN eng ko'p so'raladigan SQL mavzusi.
