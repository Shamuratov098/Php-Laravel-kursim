DARS 03 · MODUL A — POYDEVOR

Shart va solishtirish: == bilan ===

Bu darsdan keyin qaror qabul qiladigan kod yozasiz — va PHP'ning eng ko'p adashtiradigan joyini bilib olasiz: ikkita solishtirish belgisi bor va ular boshqa-boshqa javob beradi. Bu intervyuda kafolatlangan savol.

📱 O'qish ≈ 8 daqiqa 💻 Amaliyot ≈ 12 daqiqa Kerak: Dars 02

Nega bu muhim

2-darsda ko'rgan qoida esingizdami — operator tipni o'zgartiradi? Solishtirish ham operator. Ya'ni "25" == 25 degan savolga PHP rost deb javob beradi, hatto biri matn, biri son bo'lsa ham.

Bu Laravel'da har kuni uchraydi: formadan kelgan qiymat har doim matn ("25"), bazadan kelgani esa son (25). Ularni noto'g'ri solishtirsangiz — kod xato bermaydi, shunchaki jimgina noto'g'ri ishlaydi. Bunday xatolarni topish eng qiyin. Bugun uni oldini olishni o'rganamiz.

Ikkita solishtirish belgisi

BelgiNomiNima tekshiradi
==loose (bo'sh)Faqat qiymatni. Tiplar boshqa bo'lsa, avval birini o'zgartiradi
===strict (qat'iy)Qiymatni ham, tipni ham. Hech narsa o'zgartirilmaydi
tushuncha
var_dump("25" == 25); // true — qiymat bir xil var_dump("25" === 25); // false — tip boshqa (string va int)
Amaliy qoida — yodda tuting

Doim === ishlating. == ni faqat aniq sabab bo'lganda (va nima qilayotganingizni bilganda) ishlatasiz. Bu qoida sizni butun bir toifadagi xatolardan qutqaradi, va professional Laravel kodida ham shunday yozilgan.

PHP 8 eng yomon tuzoqni tuzatdi

Eski PHP'da 0 == "salom" rost edi — chunki PHP matnni songa aylantirishga urinib, uni 0 deb hisoblardi. Bu juda ko'p xavfsizlik xatosiga sabab bo'lgan. PHP 8 dan boshlab bunday emas:

var_dump(0 == "salom"); → bool(false) // PHP 8+. Eski PHP'da true edi! var_dump(0 == ""); → bool(false) var_dump("1" == "01"); → bool(true) // ikkalasi ham son sifatida o'qiladi var_dump(null == false); → bool(true) // ikkalasi ham «bo'sh»

Ko'rib turganingizdek, == ning qoidalari esda tutish qiyin. Aynan shuning uchun === tavsiya qilinadi: uning qoidasi bitta va sodda — «tip ham, qiymat ham bir xil bo'lsa rost».

Truthy va falsy: if ichida nima «rost» hisoblanadi

if qavsiga bool bo'lmagan narsa qo'ysangiz, PHP uni rost yoki yolg'onga aylantiradi. Qaysi qiymatlar yolg'on (falsy) — ro'yxati qisqa, shuning uchun shuni yodlash osonroq:

Yolg'on (falsy)Izoh
falseTabiiy
0 · 0.0Nol — son sifatida
""Bo'sh matn
"0"⚠️ Nol matn sifatida ham yolg'on
null«Qiymat yo'q»
[]Bo'sh massiv (5-darsda ko'ramiz)

Qolgan hamma narsa rost. Ya'ni "false" — rost (chunki u bo'sh bo'lmagan matn), " " (bitta bo'sh joy) — ham rost, -1 — ham rost.

Qaror qabul qilish: if / elseif / else

tushuncha
if ($holat === "yangi") { // shart rost bo'lsa shu blok ishlaydi } elseif ($holat === "korildi") { // birinchisi yolg'on, bu rost bo'lsa } else { // hech biri rost bo'lmasa }

PHP shartlarni yuqoridan pastga tekshiradi va birinchi rost topilganda to'xtaydi — qolganlariga qaramaydi. Shuning uchun tartib muhim.

match — qiymat qaytaradigan tanlov

Bir xil o'zgaruvchini bir necha qiymat bilan solishtirayotgan bo'lsangiz, match ancha toza chiqadi:

tushuncha
$matn = match ($holat) { "yangi" => "Ariza qabul qilindi", "korildi" => "Ariza ko'rildi", default => "Holat noma'lum", };

Ikkita muhim xususiyati bor:

  • Qiymat qaytaradi — natijani to'g'ridan-to'g'ri o'zgaruvchiga solasiz. if esa qaytarmaydi.
  • Har doim === bilan solishtiradi — ya'ni xavfsiz. Tip o'zgartirilmaydi.
default ni tashlab ketmang

Agar hech bir variant mos kelmasa va default yozilmagan bo'lsa, PHP to'xtaydi: Uncaught UnhandledMatchError. Ba'zida bu foydali (kutilmagan qiymatni darrov bilib olasiz), lekin bilib turib tanlash kerak.

Takrorlash: for va while

tushuncha
for ($i = 1; $i <= 3; $i++) { // 1) boshlash · 2) shart · 3) har aylanadan keyin echo $i; } while ($qolgan > 0) { // shart rost ekan — davom etadi $qolgan--; // buni yozishni unutsangiz — abadiy aylanadi! }
  • for — necha marta aylanishini oldindan bilganda.
  • while — shart buzilguncha aylanadi, soni oldindan noma'lum.
  • $i++ = «$i ni bittaga oshir», $qolgan-- = «bittaga kamaytir».
Ro'yxatni aylanish uchun foreach bor

Amalda eng ko'p ishlatiladigan sikl — foreach: u ro'yxatning har bir elementini aylanib chiqadi. Lekin u massiv talab qiladi, massivni esa hali o'rganmadik — shuning uchun foreach 5-darsda, massiv bilan birga keladi. Bu ataylab: kursda hech qachon o'rgatilmagan narsa ishlatilmaydi.

💻 Amaliy qism kompyuterda

Amaliyotda uchta fayl yozasiz: 05-solishtirish.php (== va === ni bir xil qiymatlarda yonma-yon ko'rasiz), 06-shart.php (ariza holatiga qarab xabar chiqaradi) va 07-takrorlash.php (for va while). Oxirida falsy qiymatlarni bir buyruq bilan tekshirasiz.

Amaliyot

  1. Papkaga o'ting

    cd ~/Projects/Learn/php-poydevor

    Kutilgan natija: jimlik.

  2. Solishtirishni o'z ko'zingiz bilan ko'ring

    Bu darsning yuragi. Bir xil ikki qiymat, ikki xil javob.

    cat > 05-solishtirish.php <<'EOF' <?php $kiritilgan = "25"; $kerakli = 25; var_dump($kiritilgan == $kerakli); var_dump($kiritilgan === $kerakli); EOF php 05-solishtirish.php bool(true) bool(false)

    Kutilgan natija: true, keyin false. $kiritilgan — «formadan kelgan» matn, $kerakli — «bazadan kelgan» son. Real hayotda aynan shunday bo'ladi.

  3. Shartli kod yozing

    IshTop loyihasidagi ariza holati — kursda keyin ham shu atamalar ishlatiladi.

    cat > 06-shart.php <<'EOF' <?php $holat = "korildi"; if ($holat === "yangi") { echo "Ariza navbatda turibdi"; } elseif ($holat === "korildi") { echo "Ish beruvchi arizani ko'rdi"; } else { echo "Holat noma'lum: {$holat}"; } echo PHP_EOL; EOF php 06-shart.php Ish beruvchi arizani ko'rdi

    Kutilgan natija: ikkinchi shart ishlaydi. Endi o'zingiz sinab ko'ring: faylda $holat ni "rad" ga o'zgartirib qayta bajaring — else bloki ishlashi kerak.

  4. Takrorlashni yozing

    cat > 07-takrorlash.php <<'EOF' <?php for ($i = 1; $i <= 3; $i++) { echo "{$i}-vakansiya", PHP_EOL; } $qolgan = 3; while ($qolgan > 0) { echo "Qoldi: {$qolgan}", PHP_EOL; $qolgan--; } EOF php 07-takrorlash.php 1-vakansiya 2-vakansiya 3-vakansiya Qoldi: 3 Qoldi: 2 Qoldi: 1

    Kutilgan natija: oltita qator. for yuqoriga sanadi, while pastga.

  5. Falsy qiymatlarni tekshiring

    Ro'yxatni yodlashdan ko'ra bir marta o'z ko'zingiz bilan ko'rish yaxshi.

    php -r 'var_dump((bool)"0", (bool)"false", (bool)0, (bool)"");' bool(false) bool(true) bool(false) bool(false)

    Kutilgan natija: diqqat qiling — "0" yolg'on, lekin "false" rost. Chunki "false" shunchaki bo'sh bo'lmagan matn.
    (bool) = «buni bool tipiga aylantir» — bu «cast» deb ataladi.

  6. Ishni saqlang

    git add -A git commit -m "03-dars: shart va solishtirish"

    Kutilgan natija: commit haqida xabar.

Sinab ko'ramiz

Natijani taxmin qiling

Uchta if. Qaysilari ishlaydi — ya'ni ekranda qaysi so'zlar chiqadi?

taxmin.php
<?php if ("0") { echo "birinchi", PHP_EOL; } if ("false") { echo "ikkinchi", PHP_EOL; } if (" ") { echo "uchinchi", PHP_EOL; }
Javobni ko'rish
ikkinchi uchinchi

Ya'ni birinchisi ishlamaydi, qolgan ikkitasi ishlaydi:

  • "0" — falsy ro'yxatida. PHP nol matnini ham nol deb hisoblaydi. Bu ro'yxatdagi eng kutilmagan a'zo.
  • "false" — rost. Bu shunchaki 5 harfli matn; PHP uni o'qib «yolg'on» deb tushunmaydi.
  • " " — rost. Bo'sh joy ham belgi, demak matn bo'sh emas.

Amaliy xulosa: formadan kelgan qiymatni if ($qiymat) bilan tekshirish xavfli — foydalanuvchi 0 yozsa, kod uni «bo'sh» deb o'ylaydi. Buning to'g'ri yo'li bor: if ($qiymat !== "") yoki if ($qiymat !== null) — ya'ni aynan nimani tekshirayotganingizni aniq ayting.

SAVOL 1 var_dump("25" === 25); nima qaytaradi?

=== tipni ham tekshiradi. "25" — string, 25 — int, demak yolg'on. == bo'lganda esa rost bo'lardi.

SAVOL 2 Quyidagilardan qaysi biri if ichida rost hisoblanadi?

Falsy ro'yxati qisqa: false, 0, 0.0, "", "0", null, []. "false" unda yo'q — u oddiy matn, demak rost.

SAVOL 3 match ning if dan asosiy farqi nima?

match natijani qaytaradi (o'zgaruvchiga solish mumkin) va har doim === bilan solishtiradi — shuning uchun tip tuzoqlari bo'lmaydi.

Eslab ayting

Avval o'zingiz javob bering, keyin ochib tekshiring. Oxirgi ikkitasi — 2-darsni takrorlash.

== va === farqi nima?

== faqat qiymatni tekshiradi va kerak bo'lsa tipni o'zgartiradi. === qiymat va tipni tekshiradi, hech narsa o'zgartirmaydi. Qoida: doim ===.

Falsy qiymatlarni sanab bering

false, 0, 0.0, "", "0", null, []. Qolgan hammasi rost — "false" va " " ham.

match ning ikkita xususiyati qanday?

1) Qiymat qaytaradi — to'g'ridan-to'g'ri o'zgaruvchiga solinadi. 2) Har doim === bilan solishtiradi. Mos variant topilmasa va default yo'q bo'lsa — UnhandledMatchError.

↩︎ Takrorlash: tip qayerda yashaydi — o'zgaruvchida yoki qiymatda?

Qiymatda. Shuning uchun bitta o'zgaruvchi tipini o'zgartira oladi, va kodga qarab tipni bilib bo'lmaydi — var_dump shuning uchun kerak.

↩︎ Takrorlash: "5" + 5 va "5" . 5 nima beradi?

int(10) va string "55". Operator tipni o'zgartiradi — bugungi == ham xuddi shu qoidaning davomi.

Cho'ntak xulosasi
  • == qiymatni, === qiymat va tipni tekshiradi → doim ===.
  • PHP 8 dan 0 == "salom" endi yolg'on (eski PHP'da rost edi).
  • Falsy: false · 0 · 0.0 · "" · "0" · null · []. Qolgani rost.
  • if/elseif/else — yuqoridan pastga, birinchi rostda to'xtaydi.
  • match — qiymat qaytaradi, === bilan solishtiradi, default yozilsin.
  • for — soni ma'lum · while — shart buzilguncha (kamaytirishni unutmang!).
🌱 Kelasi darslar uchun urug'

Bugun while da «kamaytirishni unutsangiz abadiy aylanadi» dedim — unda nima bo'ladi? Yoki match da default yo'q bo'lsa PHP nima deydi? Keyingi dars aynan shu haqda: PHP xato xabarlarini o'qish va ulardan qo'rqmaslik. Bu kursda ataylab erta turadi — xatoni tuzatishni bilgan odam tajriba qilishdan qo'rqmaydi, va tez o'rganadi.
