DARS 05 · MODUL A — POYDEVOR

Massiv va foreach: ko'p qiymat bitta joyda

Bu darsdan keyin ro'yxat va lug'at bilan ishlaysiz va ularni aylanib chiqasiz. Bu shunchaki yangi sintaksis emas: bazadan keladigan ma'lumotning shakli aynan shu — ya'ni bugun o'rganadigan tuzilma kursning oxirigacha qo'lingizda bo'ladi.

📱 O'qish ≈ 8 daqiqa 💻 Amaliyot ≈ 12 daqiqa Kerak: Dars 04

Nega bu muhim

Haqiqiy ilovada bitta qiymat deyarli uchramaydi — hamma narsa ro'yxat: bitta vakansiyada bir nechta ko'nikma, bitta sahifada o'nlab vakansiya, bitta nomzodda ko'p ariza.

Eng muhimi: bazadan qaytgan ma'lumot ham massiv — aniqrog'i, massivlar ichidagi massiv. Ya'ni bugun yozadigan foreach ($vakansiyalar as $v) — bu Laravel'da yozadigan kodning aynan o'zi bo'ladi. IshTop loyihasidagi vakansiyalar ro'yxati sahifasi shu bitta tushunchaga tayanadi.

Massiv — bitta nom, ko'p qiymat

Ikki shakli bor. Farqi — qiymatga qanday murojaat qilasiz:

tushuncha
// 1) Indeksli — tartib muhim, murojaat raqam bilan $konikmalar = ["PHP", "Laravel", "SQL"]; echo $konikmalar[0]; // PHP // 2) Assotsiativ — nom muhim, murojaat kalit bilan $vakansiya = ["nom" => "Backend dasturchi", "maosh" => 800]; echo $vakansiya["maosh"]; // 800

Indeks 0 dan boshlanadi — birinchi element [0], uchinchisi [2]. Bu deyarli barcha dasturlash tillarida shunday.

Mexanizm: ikkisi ham aslida bitta narsa

Bu PHP'ni tushunishning kalit nuqtalaridan biri. Indeksli va assotsiativ massiv alohida tiplar emas — PHP'da massiv har doim «kalit → qiymat» juftliklar to'plami. Indeksli massivda kalitlar shunchaki 0, 1, 2 sonlari bo'ladi.

var_dump buni yashirmaydi — o'zi ko'rsatib turadi:

array(3) { [0]=> string(3) "PHP" [1]=> string(7) "Laravel" [2]=> string(3) "SQL" }

Ko'ryapsizmi — [0], [1], [2]. Bular kalitlar. Ya'ni «indeksli massiv» degani — «kalitlari son bo'lgan massiv».

Bu nega muhim

Chunki PHP massivi ro'yxat emas, xarita. Shu bitta fakt bir nechta «g'alati» xatti-harakatni tushuntirib beradi — bugungi taxmin mashqida o'z ko'zingiz bilan ko'rasiz. Boshqa tillardan kelgan odam shu yerda ko'p adashadi.

Qo'shish va sanash

tushuncha
$konikmalar[] = "Redis"; // oxiriga qo'shadi — kalitni PHP o'zi tanlaydi $vakansiya["shahar"] = "Toshkent"; // yangi kalit qo'shadi echo count($konikmalar); // nechta element borligini beradi

foreach — massivni aylanib chiqish

3-darsda for va while ni ko'rdik. Massiv uchun esa alohida, ancha qulay sikl bor — foreach. Ikki shakli bor:

tushuncha
// 1) Faqat qiymat kerak bo'lsa foreach ($konikmalar as $konikma) { echo $konikma; } // 2) Kalit ham kerak bo'lsa foreach ($vakansiya as $kalit => $qiymat) { echo "{$kalit}: {$qiymat}"; }

$konikma va $kalit/$qiymat — nomlarni o'zingiz tanlaysiz. PHP har aylanishda navbatdagi elementni shu nomga soladi. for dan afzalligi: indeksni o'zingiz hisoblab yurmaysiz, va assotsiativ massivda ham ishlaydi (for esa ishlamaydi — u faqat raqamli indekslarni biladi).

Ichma-ich massiv = bazadan kelgan ma'lumot

Massivning elementi ham massiv bo'lishi mumkin. Bu eng ko'p uchraydigan shakl: yozuvlar ro'yxati.

tushuncha
$vakansiyalar = [ ["nom" => "Backend dasturchi", "maosh" => 800], ["nom" => "Frontend dasturchi", "maosh" => 700], ]; foreach ($vakansiyalar as $v) { echo "{$v['nom']} — {$v['maosh']} $"; }

Tashqi massiv — ro'yxat (indeksli). Har bir elementi — bitta yozuv (assotsiativ). Bazadan SELECT * FROM vacancies qilganda qaytadigan ma'lumot aynan shu shaklda bo'ladi. Shuning uchun bu tuzilmani hozir yaxshi tushunib olsangiz, C modulida (Eloquent) hech qanday yangilik bo'lmaydi.

Matn ichida kalitga murojaat — qavs ishlating

"{$v['nom']}" — shunday yozing. 2-darsdagi qoida shu yerda ham ishlaydi: qavs chegarani aniq belgilaydi. Qavssiz shakl ba'zi holatlarda ishlaydi, lekin ba'zilarida yo'q — shuning uchun bitta odat yaxshi.

Yo'q kalitni o'qisangiz — Warning

4-darsdagi bilim shu yerda ishga tushadi. Massivda bo'lmagan kalitni o'qisangiz PHP ogohlantiradi va null qaytaradi — lekin to'xtamaydi:

PHP Warning: Undefined array key "maosh" in w.php on line 4 Maosh:

Ya'ni sahifa «ishlab» turadi, faqat maosh joyi bo'sh chiqadi. Bu formadan yoki bazadan kelgan ma'lumot bilan ishlaganda eng ko'p uchraydigan holat — va Warning'ni o'qimasangiz, sababini uzoq izlaysiz.

💻 Amaliy qism kompyuterda

Amaliyotda uchta fayl yozasiz: 11-massiv.php (ikki shaklni var_dump bilan solishtirasiz va kalitlarni ko'rasiz), 12-foreach.php (ko'nikmalar ro'yxatini chiqarasiz) va 13-vakansiyalar.php (ichma-ich massiv — bazadan kelgan ma'lumot shakli). Oxirida yo'q kalitni ataylab o'qib, Warning ni chiqarasiz.

Amaliyot

  1. Papkaga o'ting

    cd ~/Projects/Learn/php-poydevor

    Kutilgan natija: jimlik.

  2. Ikki shaklni yonma-yon ko'ring

    Diqqatingiz var_dump chiqishidagi kalitlarga bo'lsin — mexanizm shu yerda ko'rinadi.

    cat > 11-massiv.php <<'EOF' <?php $konikmalar = ["PHP", "Laravel", "SQL"]; $vakansiya = ["nom" => "Backend dasturchi", "maosh" => 800, "faol" => true]; var_dump($konikmalar); var_dump($vakansiya); EOF php 11-massiv.php array(3) { [0]=> string(3) "PHP" ... array(3) { ["nom"]=> string(17) "Backend dasturchi" ...

    Kutilgan natija: ikkita array(3). Birinchisining kalitlari [0] [1] [2], ikkinchisining ["nom"] ["maosh"] ["faol"]. Ikkisi ham bir xil tip — array. Farq faqat kalitlarda.

  3. Ro'yxatni aylanib chiqing

    cat > 12-foreach.php <<'EOF' <?php $konikmalar = ["PHP", "Laravel", "SQL"]; echo "Talab qilinadigan ko'nikmalar:", PHP_EOL; foreach ($konikmalar as $konikma) { echo "- {$konikma}", PHP_EOL; } echo "Jami: ", count($konikmalar), " ta", PHP_EOL; EOF php 12-foreach.php Talab qilinadigan ko'nikmalar: - PHP - Laravel - SQL Jami: 3 ta

    Kutilgan natija: uchta chiziqchali qator va jami soni. O'zingiz sinab ko'ring: massivga "Redis" qo'shib qayta bajaring — sikl va count ikkisi ham o'zi moslashadi.

  4. Bazadan kelgan ma'lumot shaklini yasang

    Bu tuzilma C modulida (Eloquent) aynan qaytadi — shuning uchun hozir tanish bo'lib qolsin.

    cat > 13-vakansiyalar.php <<'EOF' <?php $vakansiyalar = [ ["nom" => "Backend dasturchi", "maosh" => 800], ["nom" => "Frontend dasturchi", "maosh" => 700], ]; foreach ($vakansiyalar as $v) { echo "{$v['nom']} — {$v['maosh']} $", PHP_EOL; } echo "Jami: ", count($vakansiyalar), " ta vakansiya", PHP_EOL; EOF php 13-vakansiyalar.php Backend dasturchi — 800 $ Frontend dasturchi — 700 $ Jami: 2 ta vakansiya

    Kutilgan natija: ikkita vakansiya qatori. $v — har aylanishda bitta yozuv (assotsiativ massiv), shuning uchun undan $v['nom'] bilan qiymat olinadi.

  5. Yo'q kalitni ataylab o'qing

    4-darsdagi bilimni ishga solamiz: Warning to'xtatmaydi, shuning uchun uni sezmay qolish mumkin.

    php -r '$v = ["nom" => "Backend"]; echo "Maosh: {$v["maosh"]}", PHP_EOL; echo "Davom etdi", PHP_EOL;' PHP Warning: Undefined array key "maosh" in Command line code on line 1 Maosh: Davom etdi

    Kutilgan natija: ogohlantirish, keyin bo'sh maosh, keyin dastur davom etdi. Xato turini ayta olasizmi? — Warning, demak «ishladi, lekin natijaga ishonmang».

  6. Ishni saqlang

    git add -A git commit -m "05-dars: massiv va foreach"

    Kutilgan natija: commit haqida xabar.

Sinab ko'ramiz

Natijani taxmin qiling

Ikki elementli massivga 5-indeks bilan qiymat qo'shamiz, keyin [] bilan yana bittasini. Savol: oxirgi elementning kaliti nechchi bo'ladi, va count nima qaytaradi?

taxmin.php
<?php $a = ["a", "b"]; $a[5] = "c"; $a[] = "d"; var_dump($a); echo count($a), PHP_EOL;
Javobni ko'rish
array(4) { [0]=> string(1) "a" [1]=> string(1) "b" [5]=> string(1) "c" [6]=> string(1) "d" } 4

Ikkita kutilmagan narsa bor:

  • Kalit 2, 3, 4 mavjud emas. PHP bo'shliqni to'ldirmaydi — $a[2] ni o'qisangiz Warning olasiz.
  • Oxirgi element kaliti — 6, 2 emas. $a[] = «eng katta son kalit + 1» ni oladi. Eng kattasi 5 edi → 6 bo'ldi. Ya'ni u count ga qaramaydi.

Sabab bitta: PHP massivi — ro'yxat emas, xarita. Unda «uzunlik» degan tushuncha yo'q, faqat kalitlar to'plami bor. count esa elementlar sonini beradi — eng katta kalitni emas.

Amaliy xulosa: massivni for ($i = 0; $i < count($a); $i++) bilan aylanish xavfli — kalitlar uzluksiz bo'lmasa buziladi. foreach esa har doim ishlaydi, chunki u mavjud kalitlarni oladi. Mana foreach nega tavsiya qilinadi.

SAVOL 1 PHP'da indeksli va assotsiativ massiv nima?

PHP massivi har doim «kalit → qiymat» to'plami. Indeksli massivda kalitlar shunchaki 0, 1, 2. var_dump buni o'zi ko'rsatadi: [0]=>.

SAVOL 2 Assotsiativ massivni aylanib chiqish uchun nima ishlatiladi?

for faqat raqamli indekslar bilan ishlaydi. foreach esa mavjud kalitlarni oladi — shuning uchun assotsiativ massivda ham, kalitlari uzluksiz bo'lmagan massivda ham ishlaydi.

SAVOL 3 Massivda yo'q kalitni o'qisangiz nima bo'ladi?

Warning: Undefined array key chiqadi va qiymat null bo'ladi — lekin dastur to'xtamaydi. Shuning uchun sahifa «ishlab» turib bo'sh joy ko'rsatishi mumkin.

Eslab ayting

Avval o'zingiz javob bering, keyin ochib tekshiring. Oxirgi ikkitasi — 4-darsni takrorlash.

PHP massivi — ro'yxatmi yoki xarita?

Xarita — har doim «kalit → qiymat». Indeksli massiv shunchaki kalitlari 0, 1, 2 bo'lgan xarita. Shuning uchun kalitlar uzluksiz bo'lmasligi mumkin.

foreach ning ikki shakli qanday?

foreach ($a as $qiymat) — faqat qiymat. foreach ($a as $kalit => $qiymat) — kalit ham. Nomlarni o'zingiz tanlaysiz.

Bazadan kelgan yozuvlar ro'yxati qanday shaklda bo'ladi?

Indeksli massiv ichida assotsiativ massivlar: tashqisi ro'yxat, har bir elementi bitta yozuv. foreach ($yozuvlar as $y) bilan aylanib, $y['ustun'] bilan qiymat olinadi.

↩︎ Takrorlash: Warning va Fatal error farqi?

Warning — kod davom etadi (natijaga ishonmang). Fatal error — kod to'xtaydi (bir qismi bajarilgan, qolgani yo'q).

↩︎ Takrorlash: Parse error da qaysi qatorga qaraladi?

Ko'rsatilgan qatorda topmasangiz — bir qator yuqoriga. PHP muammoni keyingi ko'rsatma boshlanganda sezadi.

Cho'ntak xulosasi
  • Massiv — bitta nom, ko'p qiymat. Ikki shakl: indeksli ([0]) va assotsiativ (["kalit"]).
  • Ikkisi ham bitta tip — massiv har doim «kalit → qiymat» xaritasi.
  • $a[] = $x qo'shadi (eng katta son kalit + 1) · count($a) sanaydi.
  • foreach ($a as $q) yoki foreach ($a as $k => $q) — massiv uchun eng to'g'ri sikl.
  • Ichma-ich massiv = yozuvlar ro'yxati — bazadan keladigan ma'lumot shakli.
  • Yo'q kalit → Warning + null, dastur davom etadi.
  • Matn ichida: "{$v['nom']}" — qavs ishlating.
🌱 Kelasi darslar uchun urug'

Massiv bilan ishlashning eng kuchli usullari bor: «har bir elementni o'zgartir» (array_map) yoki «shartga mos kelganini tanla» (array_filter). Lekin ular sizdan funksiya talab qiladi — «bu elementga nima qilay?» degan savolga javobni funksiya shaklida berasiz. Shuning uchun ular keyingi darsda, funksiya bilan birga keladi. Laravel'da esa bularning ancha chiroyli ko'rinishi bor — Collections — va u G modulida ochiladi.
