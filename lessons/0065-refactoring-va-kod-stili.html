DRY — va uning xavfi

DRY — «Don't Repeat Yourself», takrorlanmang. Testlarimizda oltita joyda bir xil tayyorgarlik bor edi:

Vakansiya::factory()->create([ 'kompaniya_id' => Kompaniya::factory(), 'user_id' => User::factory(), 'faol' => true, 'muddat' => null, ]);

Uni bitta yordamchiga chiqardik:

function vakansiya(array $ustunlar = []): Vakansiya { return Vakansiya::factory()->create($ustunlar + [...]); } // endi: vakansiya(['faol' => false])
⚠️ Lekin DRY ni erta qo'llash — zarar

Eng ko'p uchraydigan xato: o'xshash ko'ringan ikki kodni birlashtirish.

// bugun bir xil ko'rinadi: function narxHisobla($summa) { return $summa * 1.12; } // QQS function bonusHisobla($summa) { return $summa * 1.12; } // bonus // birlashtirdik: function koeffitsiyentBilan($summa) { return $summa * 1.12; } // ertaga QQS 15% bo'ldi. Bonus esa 12% qoldi. ⚠️ // Endi birlashtirilgan funksiyani AJRATISH kerak.

🔑 Qoida: kod takrorlanishi emas, BILIM takrorlanishi yomon.

Bir xil BILIM ikki joyda → birlashtiring ✅ Tasodifan bir xil KO'RINISH → tegmang ⚠️

Sinov: «bu ikkitasi doim birga o'zgaradimi?» Ha bo'lsa — birlashtiring. Yo'q bo'lsa — qoldiring.

✅ Amaliy maslahat: takrorlanishni uchinchi marta ko'rganingizda birlashtiring. Ikki marta — hali tasodif bo'lishi mumkin.
