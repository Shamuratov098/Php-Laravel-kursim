DARS 01 · MODUL A — POYDEVOR

PHP qanday ishlaydi: brauzerdan serverga

Bu darsdan keyin birinchi PHP sahifangiz brauzerda ishlaydi — va eng muhimi, brauzer aslida nimani olganini ayta olasiz. Shu bitta tushuncha keyinchalik Laravel'ni «sehr» emas, mexanizm sifatida ko'rishning kaliti bo'ladi.

📱 O'qish ≈ 6 daqiqa 💻 Amaliyot ≈ 12 daqiqa Kerak: hech narsa — birinchi dars

Nega bu muhim

Sizning maqsadingiz — backend dasturchi bo'lib ishga kirish. Backend degani aslida bitta ish: so'rov keladi, javob qaytadi. Laravel'ning butun mavjudligi shu aylanani qulay qilish uchun. Agar shu aylana ko'rinmasa, return view(...) ham, API'dan qaytgan JSON ham «qandaydir tarzda o'zi ishlaydi» bo'lib qoladi.

Bundan tashqari bu intervyuning eng birinchi savoli: «PHP qanday ishlaydi?». Bugun shu savolga to'liq javob berishni o'rganamiz.

PHP — matn ishlab chiqaradigan mashina

PHP serverda ishlaydi. U brauzerga yuborilmaydi, brauzerda bajarilmaydi. Uning yagona vazifasi — kodni bajarib, natijada matn hosil qilish. O'sha matn odatda HTML bo'ladi, lekin JSON, CSV yoki oddiy so'z ham bo'lishi mumkin — PHP uchun farqi yo'q.

1 · Brauzer so'raydi

HTTP request
Siz manzilni yozasiz. Brauzer serverga xat yuboradi: «menga /sahifa.php ni ber».

2 · Server qaraydi

web server
Faylni topadi. Kengaytmasi .php ekan — o'zi o'qimaydi, PHP'ga uzatadi.

3 · PHP bajaradi

interpreter
Kodni yuqoridan pastga bajaradi va natijada matn to'playdi. Kod shu yerda qoladi.

4 · Brauzer oladi

HTTP response
Faqat tayyor matn yetib boradi. PHP kodidan bir belgi ham chiqmaydi.
Uchinchi qadam eng muhimi

PHP kodi hech qachon brauzerga bormaydi. Shuning uchun sahifada «ko'rish manbasi» (view source) ni ochsangiz, <?php ni topa olmaysiz — u yerda faqat natija turadi. Amaliyotda buni o'z ko'zingiz bilan ko'rasiz, va bu darsning asosiy g'alabasi shu.

PHP fayl ichida ikki hudud bor

PHP fayli — bu «hammasi kod» degani emas. Fayl ikki hududdan iborat:

  • <?php va ?> orasi — PHP hududi. Bu yerdagi narsa bajariladi.
  • Tashqarisi — matn hududi. PHP unga tegmaydi, o'zgarmasdan javobga qo'shib yuboradi.2

Ya'ni <?php — bu «PHP rejimiga kirish» eshigi, ?> esa «chiqish» eshigi. Fayl matn rejimida boshlanadi.

Kod: ikkita fayl

Amaliyotda ikkita fayl yozasiz. Ularni avval o'qib chiqamiz — har bo'lagining ma'nosi bilan.

Birinchisi: eng kichik PHP fayli

php-poydevor/01-salom.php yangi
<?php echo "Salom, dunyo!";

Uchta narsani ajratib olamiz:

  • <?php — PHP hududi shu yerdan boshlanadi. Undan keyin albatta bo'sh joy yoki yangi qator kerak, aks holda xato chiqadi.2
  • echo — «javobga shu matnni qo'sh» degan buyruq. U ekranga chizmaydi, javobga yozadi — bu farq keyinroq muhim bo'ladi.
  • ; — nuqtali vergul. Har bir ko'rsatmaning oxiri. Tushib qolsa PHP keyingi qatorni shu ko'rsatmaning davomi deb o'qiydi va syntax error beradi.
Nega oxirida ?> yo'q?

Ataylab. Agar fayl faqat PHP kodidan iborat bo'lsa, yopuvchi ?> ni yozmaslik tavsiya etiladi.2 Sababi amaliy: ?> dan keyin adashib qo'yilgan bitta bo'sh qator ham javobga tushib ketadi va keyinchalik tushunarsiz xatolarga olib keladi. Laravel'ning barcha PHP fayllari ham shu qoida bilan yozilgan — o'zingiz ko'rasiz.

Ikkinchisi: HTML va PHP aralash

php-poydevor/02-sahifa.php yangi
<h1>Mening sahifam</h1> <p>Bugun: <?php echo date("Y-m-d"); ?></p> <p>Bu qator PHP'ga tegmagan.</p>

Bu faylda uch qator HTML bor, lekin ulardan bittasining o'rtasida PHP hududi ochilgan (ajratib ko'rsatilgan). PHP faqat o'sha bo'lakni bajaradi: date("Y-m-d") bugungi sanani beradi, echo uni javobga qo'yadi. Qolgan hamma narsa o'zgarmasdan o'tadi.

Natija — toza HTML:

<h1>Mening sahifam</h1> <p>Bugun: 2026-08-10</p> <p>Bu qator PHP'ga tegmagan.</p>

Diqqat qiling: <?php ... ?> o'rnida endi faqat 2026-08-10 turadi. Kod g'oyib bo'ldi — chunki u bajarildi, va o'zidan keyin faqat natijasini qoldirdi.

💻 Amaliy qism kompyuterda

Amaliyotda php-poydevor/ papkasida ikkita fayl yozasiz, ularni avval terminalda (php fayl.php), keyin brauzerda (php -S) ishga tushirasiz. Yakuniy qadam eng qiziqlisi: brauzerda «ko'rish manbasi» ni ochib, PHP kodining yo'qligini o'z ko'zingiz bilan tasdiqlaysiz. Kompyuterda ochganingizda 7 qadamlik yo'riqnoma, Copy tugmasi va kutilgan natijalar chiqadi.

Amaliyot

Papka allaqachon tayyorlab qo'yilgan: ~/Projects/Learn/php-poydevor/. Barcha Modul A mashqlari shu yerda yashaydi.

  1. Papkaga o'ting va PHP borligini tekshiring

    Har ishni «bor-yo'qligini tekshirish»dan boshlash — professional odat. Buyruq ishlamasa, muammo kodda emas, muhitda ekanini darrov bilasiz.

    cd ~/Projects/Learn/php-poydevor php -v PHP 8.3.32 (cli) (built: Jul 2 2026 18:10:58) (NTS)

    Kutilgan natija: versiya raqami chiqadi. (cli) so'zi muhim — bu «command line interface», ya'ni PHP hozir terminal orqali ishlayapti.

  2. Birinchi faylni yarating

    Ikki qator — PHP faylining eng kichik ko'rinishi.

    printf '<?php\necho "Salom, dunyo!";\n' > 01-salom.php

    Kutilgan natija: terminal jim turadi. Fayl yaratildi — matn muharririda ochib ham ko'rishingiz mumkin.

  3. Terminalda bajaring

    Hozircha server ham, brauzer ham kerak emas. PHP mustaqil dastur — faylni to'g'ridan-to'g'ri bajara oladi.

    php 01-salom.php Salom, dunyo!

    Kutilgan natija: Salom, dunyo! chiqadi (oxirida yangi qator bo'lmaydi — echo o'zi qator tashlamaydi).

  4. Ikkinchi faylni yarating — HTML bilan aralash

    Endi ikki hudud bir faylda: HTML va PHP.

    cat > 02-sahifa.php <<'EOF' <h1>Mening sahifam</h1> <p>Bugun: <?php echo date("Y-m-d"); ?></p> <p>Bu qator PHP'ga tegmagan.</p> EOF

    Kutilgan natija: yana jimlik. ls qilsangiz ikkita .php fayl turadi.

  5. Uni ham terminalda bajaring

    Natijani ko'rib, PHP nimani o'zgartirib, nimaga tegmaganini solishtirasiz.

    php 02-sahifa.php <h1>Mening sahifam</h1> <p>Bugun: 2026-08-10</p> <p>Bu qator PHP'ga tegmagan.</p>

    Kutilgan natija: HTML teglar o'zgarmagan, faqat <?php ... ?> o'rnida bugungi sana turadi. Sana albatta bugungi kun bo'ladi.

  6. Endi veb-server ishga tushiring

    Terminal — bu siz. Brauzer — bu foydalanuvchi. Ikkinchisini sinash uchun server kerak. PHP'ning o'zida kichik server bor.3

    php -S localhost:8000 [Mon Aug 10 16:25:59 2026] PHP 8.3.32 Development Server (http://localhost:8000) started

    Kutilgan natija: «Development Server ... started» va terminal band bo'lib qoladi — bu normal, server ishlab turibdi. To'xtatish uchun Ctrl+C. Keyingi qadamlar uchun yangi terminal oynasi oching yoki shunchaki brauzerga o'ting.

  7. Brauzerda ochib, manbani ko'ring — darsning asosiy g'alabasi

    Bu qadam butun darsning isboti. Brauzerga PHP kodi bormaganini o'z ko'zingiz bilan ko'rasiz.

    xdg-open http://localhost:8000/02-sahifa.php

    Kutilgan natija: sahifada katta sarlavha va bugungi sana ko'rinadi. Endi o'ng tugma → «Sahifa manbasini ko'rish» (yoki Ctrl+U). U yerda:

    <h1>Mening sahifam</h1> <p>Bugun: 2026-08-10</p> <p>Bu qator PHP'ga tegmagan.</p>

    <?php so'zi yo'q. echo ham yo'q. date ham yo'q. Faqat natija. 🎉

Sinab ko'ramiz

Natijani taxmin qiling

Quyidagi fayl brauzerga aynan nimani yuboradi? Avval o'zingiz aytib ko'ring — keyin ochib tekshiring. (Bu yerda kichik tuzoq bor.)

taxmin.php
<p>Bir</p> <?php echo "<p>Ikki</p>"; ?> <p>Uch</p>
Javobni ko'rish

Uchta paragraf ham chiqadi — lekin ikkinchi va uchinchisi bitta qatorda:

<p>Bir</p> <p>Ikki</p><p>Uch</p>

Nega? Chunki ?> o'zidan keyin darhol kelgan yangi qatorni yeb yuboradi — bu PHP'ning hujjatlashtirilgan xatti-harakati.2 Shu sababli <p>Uch</p> oldingi qatorga yopishib qoldi.

HTML uchun bu muammo emas (brauzer baribir bir xil ko'rsatadi), lekin bu detal nega muhim: agar siz fayl yoki JSON chiqarayotgan bo'lsangiz, bitta adashgan qator butun natijani buzadi. Aynan shu sababdan faqat PHP'dan iborat fayllarda ?> yozilmaydi.

SAVOL 1 Brauzer .php sahifani so'raganda unga aslida nima yetib boradi?

PHP serverda bajariladi va faqat natijani javobga qo'yadi. Shuning uchun «manbani ko'rish»da <?php topilmaydi — kod serverda qoldi.

SAVOL 2 <?php ... ?> hududidan tashqarida turgan HTML bilan nima bo'ladi?

PHP teglar tashqarisidagi hamma narsani e'tiborsiz qoldiradi va o'zgarishsiz o'tkazadi. Shuning uchun .php faylni deyarli butunlay HTML qilib yozish ham mumkin.

SAVOL 3 php -S localhost:8000 nima qiladi?

Bu PHP'ning ichida kelgan kichik veb-server — o'rganish va sinash uchun.3 Terminal band bo'lib qoladi, chunki server so'rovlarni kutib turadi. Haqiqiy saytlar uchun mo'ljallanmagan — J modulida asl server bilan tanishamiz.

Eslab ayting

Avval o'zingiz javob bering, keyin ochib tekshiring. Yodlab olishning eng tez yo'li — qarab emas, eslab aytish.

So'rovdan javobgacha to'rtta qadam qanday?

1) Brauzer so'raydi → 2) server faylni topib PHP'ga uzatadi → 3) PHP kodni bajaradi va matn hosil qiladi → 4) brauzer faqat o'sha matnni oladi.

echo aslida qayerga yozadi?

Ekranga emas — javobga. Terminalda bajarsangiz javob terminalga tushadi, brauzer orqali so'rasangiz brauzerga. Manzil o'zgaradi, ish bir xil.

PHP fayli ichidagi ikki hudud qaysi?

<?php ... ?> ichi — bajariladigan kod. Tashqarisi — o'zgarmasdan o'tadigan matn. Fayl matn rejimida boshlanadi.

Nega faqat PHP'dan iborat faylda ?> yozilmaydi?

Chunki undan keyingi adashgan bo'sh qator javobga tushib ketadi va tushunarsiz xatolar keltiradi. Laravel fayllari ham shu qoida bilan yozilgan.

Cho'ntak xulosasi
  • PHP serverda ishlaydi. Brauzerga kod emas, faqat natija boradi.
  • Aylanasi: so'rov → server → PHP → javob. Backend'ning butun ishi shu.
  • <?php ichi bajariladi, tashqarisi o'zgarmasdan o'tadi.
  • echo = «javobga matn qo'sh» · ; = ko'rsatma oxiri.
  • php fayl.php = terminalda · php -S localhost:8000 = brauzerda.
  • Faqat PHP'dan iborat faylda ?> yozilmaydi.
🌱 Kelasi darslar uchun urug'

Hozir URL = fayl yo'li: /02-sahifa.php so'rasangiz, server aynan shu nomli faylni izlaydi. Laravel bu qoidani butunlay buzadi — u yerda /vakansiyalar/12 degan URL bo'ladi, lekin bunday nomli fayl mavjud bo'lmaydi. O'sha mexanizm routing deb ataladi va biz unga 18-darsda yetib boramiz. Bugungi «URL = fayl» modelini yodda tuting — routing'ni tushunish uchun aynan shu solishtirish kerak bo'ladi.
