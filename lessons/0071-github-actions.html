Workflow fayli

GitHub Actions bitta narsani qidiradi: .github/workflows/ papkasidagi YAML fayllar.

.github/workflows/testlar.yml
name: Testlar on: push: branches: [main] pull_request: jobs: sinov: runs-on: ubuntu-latest steps: - name: Kodni olish uses: actions/checkout@v4 - name: PHP o'rnatish uses: shivammathur/setup-php@v2 with: php-version: '8.3' extensions: pdo_sqlite, mbstring, bcmath coverage: none - name: Composer keshi uses: actions/cache@v4 with: path: vendor key: composer-${{ hashFiles('composer.lock') }} - name: Bog'liqliklarni o'rnatish run: composer install --prefer-dist --no-interaction --no-progress - name: Muhitni tayyorlash run: | cp .env.example .env php artisan key:generate - name: Kod uslubi (Pint) run: ./vendor/bin/pint --test - name: Testlar (Pest) run: php artisan test - name: Zaifliklarni tekshirish run: composer audit
🔑 Har bo'limning ma'nosi
on: QACHON ishga tushsin push → main ga har push da pull_request → har PR da (va PR yangilanganda) runs-on: QAYERDA — GitHub bergan toza Ubuntu mashinasi uses: tayyor "action" (boshqalar yozgan qadam) run: oddiy shell buyrug'i

🔍 Har ishga tushishda mashina butunlay yangi — hech qanday eski fayl, kesh yoki sozlama qolmaydi. Bu 68-darsdagi Docker g'oyasining davomi.

⚠️ Shuning uchun .env ni o'zimiz yaratamiz — .env.example dan (66-darsdan: .env git'da yo'q).
