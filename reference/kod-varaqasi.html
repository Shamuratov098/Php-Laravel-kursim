Kod varaqasi

Amaliyot paytida yonida turadigan varaq: buyruqlar, kod naqshlari va muhit ma'lumotlari. Har dars yangi buyruq o'rgatilsa, shu yerga qo'shiladi.

Qamrov: 1-dars — muhit va ishga tushirish Har dars bilan to'ldiriladi 💻 Amaliyotga mos

Bu hujjat o'sib boradi

Har bir buyruq shu yerga faqat jonli sinovdan o'tgandan keyin qo'shiladi. Artisan, Eloquent va Blade naqshlari o'z darsi yozilganda paydo bo'ladi.

Massiv

KodMa'nosi
["PHP", "SQL"]Indeksli — kalitlari 0, 1
["nom" => "Backend"]Assotsiativ — kaliti nom
$a[0] · $a["nom"]Qiymatni o'qish
$a[] = "yangi";Oxiriga qo'shadi — «eng katta son kalit + 1»
count($a)Elementlar soni (eng katta kalit emas!)
foreach ($a as $q)Qiymatlarni aylanadi
foreach ($a as $k => $q)Kalit va qiymatni aylanadi
"{$v['nom']}"Matn ichida kalit — qavs ishlating
PHP massivi — xarita, ro'yxat emas

Har doim «kalit → qiymat». Kalitlar uzluksiz bo'lmasligi mumkin, shuning uchun for ($i=0; $i<count($a); $i++) xavfli — foreach ishlating.
Yo'q kalitni o'qish → Warning: Undefined array key + null, dastur davom etadi.

OOP — klass va obyekt

KodMa'nosi
class Vakansiya { }Chizma. Bir marta yoziladi, o'zi tipga aylanadi
$v = new Vakansiya(...)Obyekt yasaydi. Har new — mustaqil obyekt
public function __construct()Obyekt yasalganda avtomatik ishlaydi
$this->nom«Aynan shu obyektning» xossasi. Metod ichida shart
$v->nom · $v->metod()Obyektga murojaat
Klass::CONST · self::$xKlassga murojaat — obyekt kerak emas

require 'fayl.php';Faylni qo'shadi (10-darsda avtomatlashtiriladi)
Obyekt = bilan nusxalanmaydi

Massiv: $b = $a → mustaqil nusxa.
Obyekt: $b = $a → ikki nom, bitta obyekt. Nusxa uchun clone.

OOP — meros, interface, trait

KodMa'nosi
class B extends AMeros. B, A ning hamma narsasini oladi. Faqat bitta ota
parent::metod()Otaning versiyasini chaqirish
parent::__construct(...)⚠️ Avlodda konstruktor yozsangiz — shart
abstract class XObyekt yasab bo'lmaydi, faqat asos
abstract function f();Tanasi yo'q — avlod yozishi shart (xato e'londa chiqadi)
$x instanceof AAvlod ikkala tipga mos keladi
interface I { f(); }Shartnoma — faqat imzolar, kod yo'q
class C implements I, JBir nechta shartnoma mumkin
trait T { ... } · use T;Kodni klass ichiga ko'chiradi. Tip bermaydi
static::class«Hozir men qaysi klass ichidaman»
get_class($x)Obyektning klass nomi
interface yoki trait — qaysi biri?

Tip kerak bo'lsa → interface («nima qila oladi», kod yo'q, f(Yuboruvchi $x) yozish mumkin).
Takrorlanadigan kodni yo'qotish kerak bo'lsa → trait («qanday qiladi»).
Metod ustunligi: o'z klassi > trait > ota klass — trait otani yengadi.

Exception — xatoni tutish

KodMa'nosi
throw new Xato("xabar");Otadi; funksiya darhol to'xtaydi
try { } catch (Tur $e) { }Tutadi, keyin dastur davom etadi
finally { }Har holda ishlaydi (tozalash uchun)
$e->getMessage()Xato matni. Yana: getFile(), getLine()
class X extends Exception {}O'z xatosi — bo'sh tanasi bilan ham foydali (nom beradi)
catch (Throwable $e)Hammasini tutadi
Error ≠ Exception

Ular aka-uka, otasi — Throwable.
catch (Exception) → DivisionByZeroError va TypeError ni tutmaydi.
Exception = kutilgan muammo (tutiladi) · Error = dasturchi xatosi (tuzatiladi).
Bir necha catch: aniqdan umumiyga. Xatoni jimgina yutmang.

HTTP — forma, XSS, session

KodMa'nosi

Session: ma'lumot serverda, kaliti cookie'da. Cookie'siz — server tanimaydi.

SQL (21-darsdan)

SQL / kodMa'nosi
DB::select('SELECT ...')Natija qaytaradigan so'rov (obyektlar massivi)
DB::statement('CREATE ...')Natija qaytarmaydigan so'rov
DB::select('... WHERE nom = ?', [$nom])🔒 Foydalanuvchi qiymati — faqat shunday. Satrga qo'shish = SQL injection
SELECT * FROM jadvalBarcha ustun · SELECT nom, maosh — faqat kerakligi
WHERE maosh > 700Shart. > qat'iy — 700 kirmaydi; >= kiradi
WHERE shahar = 'Toshkent'Matn bittalik tirnoqda
AND · ORBir necha shart
IS NULL · IS NOT NULL⚠️ = NULL ishlamaydi — hech qachon rost bo'lmaydi
ORDER BY maosh DESCKamayish tartibida; ASC — o'sish (standart)
LIMIT 2Faqat birinchi 2 qator
COUNT(*) AS soniQatorlar soni; AS — ustunga nom
PRIMARY KEY AUTOINCREMENTTakrorlanmas raqam, o'zi ortadi
NOT NULL · DEFAULT 1Baza darajasidagi qoidalar
DROP TABLE IF EXISTSSkriptni qayta ishga tushirish mumkin bo'lishi uchun

Tartib o'zgarmaydi: SELECT → FROM → WHERE → ORDER BY → LIMIT.

SQL skriptining boshi (Laravel'ni qo'lda yuklash): require vendor/autoload.php → $app = require bootstrap/app.php → $app->make(Kernel::class)->bootstrap(). Uchinchisi yo'q bo'lsa: «A facade root has not been set».

php artisan db bu kompyuterda ishlamaydi — sqlite3 buyruq qatori o'rnatilmagan.

SQL — yozish va birlashtirish (22-dars)

SQL / kodMa'nosi
DB::insert('... VALUES (?, ?)', [$a, $b])Qo'shish. Yangi id — DB::getPdo()->lastInsertId()
DB::update(...) · DB::delete(...)Nechta qator o'zgargan/o'chganini qaytaradi
UPDATE ... SET ustun = ? WHERE ...⚠️ WHERE unutilsa — butun jadval, xato bermaydi
ALTER TABLE ... ADD COLUMNMavjud jadvalga ustun. Bir martalik — ikkinchi marta «duplicate column name»
JOIN k ON k.id = v.kompaniya_idJuftligi bor qatorlar. Juftsizlar tushib qoladi
LEFT JOINChapdagi hamma qator qoladi; juftlik yo'q bo'lsa o'ng tomon NULL
FROM vakansiyalar vAlias — bir xil nomli ustunlarni ajratish uchun (v.nom, k.nom)
GROUP BY k.idGuruhlab, har guruhni bitta qator qiladi
COUNT/SUM/AVG/MIN/MAXGuruh funksiyalari. COUNT(*) qatorlarni, COUNT(ustun) NULL bo'lmaganlarni
HAVING COUNT(*) > 1Guruhlarni filtrlash (WHERE guruhlashdan oldin ishlaydi)

To'liq tartib: SELECT → FROM → JOIN → WHERE → GROUP BY → HAVING → ORDER BY → LIMIT.

⚠️ LEFT JOIN dan keyin WHERE da o'ng jadval ustunini ishlatsangiz — u jimgina oddiy JOIN ga aylanadi (NULL qatorlar tushadi). Shartni ON ga yozing.
