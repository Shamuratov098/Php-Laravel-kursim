# PHP va Laravel — 0 dan ishga tayyorgacha

O'zbek tilida bepul PHP va Laravel kursi. Sof PHP poydevoridan boshlab, junior/mid
backend dasturchi darajasigacha — **10 modul, 73 dars**.

> **Holat:** reja tuzilgan va tasdiqlangan (2026-08-10). Darslar tartib bilan qo'shib
> borilyapti — har biridagi kod jonli sinovdan o'tgan va har da'vo manbaga havola qilingan.

## Kimga mo'ljallangan

- Laravel'ni **ishlatadigan, lekin mexanizmini tushunmaydigan** dasturchilarga —
  ayniqsa kodni AI yordamida yozib kelganlarga
- PHP'ni **noldan**, tartib bilan o'rganmoqchi bo'lganlarga
- Inglizcha materialdan ko'ra **o'zbekcha** o'qishni qulay ko'radiganlarga

Bu kursning markaziy g'oyasi — **sehrni ochish**. 14–15-darslarda siz o'z qo'lingiz bilan
kichik framework yozasiz (`router` + `container`), va keyinchalik Laravel'ning har bir
«o'zi ishlab ketadigan» joyiga kelganda o'sha kodga qaytamiz.
